# neptsBI (demo)

Fleet and base information for a patient transport service: a demo with made-up data.
Sign-in tiles, then each role sees its own view. Every number can be tapped to drill down.

- `index.html`: sign-in tiles · `app.html`: the app · `neptsbi.js`/`neptsbi.css`: shared code
- `dougs.css`/`dougs.js`: the shared look (same as the parking app)
- `sql/`: database set-up (run in Supabase) · `tools/`: demo data generator
- See `SETUP.md`.
